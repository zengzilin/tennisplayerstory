# SEO 审查：2026-10-02

范围：线上页面、原始 HTML、React 渲染后的 SEO 标签、站点地图与当前代码。此报告未修改 SEO 功能，也未取得 Search Console 的收录或排名数据。

## 优先处理

1. **页面 canonical 与语言路由不一致。** 线上 `/en/news` 指向 `/news`，后者会被前端导向语言首页。各语言页应指向本语言的真实规范地址；补齐德语 hreflang，并让 x-default 指向可用入口。代码：`apps/web/src/components/SEOHelmet.tsx`。
2. **视频页的元信息参数无效。** `/en/vlogs` 实际显示首页标题、首页描述和根目录 canonical。视频列表与详情传入 `title`、`description`，而组件读取 `overrideTitle`、`overrideDescription`。需显式传入 pageKey 和真实页面路径。代码：`VlogsPage.tsx`、`VlogDetailPage.tsx`。
3. **内容承诺与真实数据不一致。** `useMatchData.js` 返回固定示例赛果，却标为 Live；首页宣传逐分实时比分。首页 584 名球员、1,240 个视频、89,000 月浏览量和 12 个社区均为硬编码。应接入真实来源，或明确标注示例并移除未经证实的规模数字；排名显示数据来源和实际更新时间。
4. **原创文章缺少独立可索引详情页。** 当前主要在列表中点按钮展开，虽支持 `?article=ID`，没有独立文章路由、文章专属 title/description/canonical。Article JSON-LD 引用了不存在的 `/stories/{id}`。应先建立真实详情页，再让标题、相关文章及 sitemap 指向它。

## 内容与展示细节

5. **News 的简介偏口号。** 当前 description 为 “Headlines that matter…”；建议用准确的内容范围说明，例如：`Read ATP and WTA tennis headlines, Grand Slam updates and publisher-provided RSS excerpts from ESPN and BBC Sport, with original links and source update times.`。H1 可包含 `Tennis News`，同时保留 Tennis Brief 品牌和现有视觉样式。
6. **RSS 聚合需要独有价值。** 来源、发布时间和摘要归属说明应保留。增长内容可增加人工核实的赛事背景、事件时间线或“为什么值得关注”的解读，并引用原始来源。不要仅批量改写标题或凭空补充事实，也不要把聚合摘要标为本站原创新闻。
7. **结构化数据与真实页面对齐。** News 当前无 JSON-LD，可加入准确的 BreadcrumbList、CollectionPage / ItemList；不要把第三方摘要伪装成本站 NewsArticle。首页 SearchAction 指向未实现的 `/search`；Organization 引用的社交链接和 logo 应只保留实际存在、归本站所有的资源。
8. **分享图片不可用。** 配置的 `/og-image.jpg` 线上返回 422；`/logo.png` 返回 HTML 而非图片。需发布真实图片，验证 Content-Type、可访问性与分享预览。
9. **初始 HTML 不含页面正文与专属元信息。** `/en/news`、`/en/players` 的初始响应只有空 root 和标题 TennisHub。Google 可以执行 JavaScript，但当前内容依赖后续渲染；可考虑在不改变功能的前提下对重点索引页面做服务端渲染或预渲染，并避免缓存旧新闻内容。
10. **索引规则需区分内容类型。** 线上 sitemap 当前有 60 个静态页面，未收录原创文章详情。原始文章建立真实规范 URL 后再加入；站内搜索和筛选组合需单独制定索引策略，分页不可简单全部归并到第一页。中文等页面的英文 RSS 正文应保留其实际语言标记，不要宣称已翻译。

建议实施顺序：canonical 与视频元信息 → 内容真实性 → 原创文章详情与内链 → 新闻简介及可信原创解读 → 结构化数据、图片与渲染。
